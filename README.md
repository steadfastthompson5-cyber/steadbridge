# SteadBridge website starter

This folder contains a static website starter for the SteadBridge project.

## Before publishing
1. Replace the sample email address `steadbridge.contact@example.com` in `index.html` with an official monitored contact address, or remove the email links until one exists.
2. Complete and legally review `privacy.html`. It is intentionally marked as a draft and must not be presented as a finished privacy policy.
3. Add the real Android APK download link only after uploading and testing the intended release APK.
4. Check all website text and business details for accuracy.

## GitHub Pages
In the GitHub repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will display the published website address when deployment completes.
